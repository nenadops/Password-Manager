

# 🔐 Secure Password Manager & Personal Data

A lightweight, modern, and user-friendly desktop application built with Python (`tkinter`) for securely managing your personal profile details (Gmail, Phone Number) and credentials/passwords for various online services.

---

## 🚀 Features

- **Personal Profile Overview:** Easily store and display core contact details like Gmail and phone numbers.
- **Credential Management:** Save, view, edit, and delete usernames and passwords for different web services and apps.
- **Password Visibility Toggle:** Show or hide passwords using a handy toggle button (`👁`) during entry.
- **Modern UI Design:** Clean, professional layout featuring a custom styled `ttk.Treeview` table, modern color palette, and intuitive form controls.
- **Persistent Local Storage:** Automatically saves all profiles and passwords into a local `passwords.json` file.

---

## 📋 Prerequisites

Make sure you have **Python 3.x** installed on your system. 
*(Note: `tkinter`, `json`, and `os` are built-in Python standard libraries, so no external package installation via `pip` is required!)*

## 🛠️ Installation & Running

1. Clone or download this repository to your local machine.
2. Open your terminal or command prompt inside the project folder.
